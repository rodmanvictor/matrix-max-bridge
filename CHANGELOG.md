# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версии следуют Semantic Versioning.

## [0.14.0] — 2026-11-26

Первый выпуск под именем matrix-max-bridge, продолжение pymatrix-max 0.12.0.
Номер 0.13 пропущен, чтобы не путать с веткой `release/v0.13.1` исходного проекта.

### Добавлено

- вход по QR-коду MAX Web в интерактивном терминале (`python -m mautrix_max.qr_cli`);
  мост подхватывает готовую сессию и восстанавливает состояние синхронизации;
- архив сообщений, контактов и чатов в базе моста (таблицы `max_archive_*`) и
  индексация истории выбранных чатов по запросу;
- локальный HTTP API через Unix-сокет (`MAX_RPC_MXID`, `MAX_RPC_SOCKET`): поиск,
  история, вложения, открытие комнат, см. `API.md`;
- отложенные сообщения средствами самого MAX: текст, фото, видео и файлы, список
  и отмена;
- утилиты `tools/matrix-max` (локальный API) и `tools/matrix-agent` (Matrix
  Client-Server API);
- `requirements.lock` с проверенными версиями зависимостей, Docker-образ ставит
  зависимости из него;
- офлайн-тесты на подставных объектах в `tests/`.

### Изменено

- PyMax обновлён до 2.5.0;
- `!max login` больше не принимает телефон, коды и пароль в Matrix;
- групповые portal хранятся с пустым `receiver` вместо NULL, чтобы составной
  ключ работал в PostgreSQL (миграция в `db/upgrade.py`);
- из логов убраны тексты сообщений и данные авторизации.

### Известные ограничения

- поиск по архиву неполный, все ответы помечены `partial`;
- архив хранит тексты сообщений: ограничьте доступ к базе и резервным копиям;
  политики удаления из архива пока нет;
- любой, кто может открыть Unix-сокет, отправляет сообщения от имени владельца;
- после `!max logout` новый вход по QR требует вручную перенести каталог сессии.

## [0.12.0] — 2026-07-17

Первый публичный preview-релиз.

### Добавлено

- многопользовательские MAX-сессии, изолированные по Matrix-пользователю;
- стабильный профиль Android-устройства для каждой MAX-сессии;
- авторизация по телефону, коду и паролю двухфакторной защиты;
- уведомления об истечении login token и диагностика reconnect;
- личные чаты, группы и каналы;
- создание DM по номеру телефона;
- вступление в группу/канал по invite-ссылке;
- выход, локальная блокировка и автоматический выход при повторном добавлении;
- таблица владельцев общих групповых portal и ручная команда `syncgroups`;
- relay-режим групп через bridge bot без массовой регистрации ghost-пользователей;
- текст, фото, видео, аудио, голосовые и файлы в обе стороны;
- сборка входящего MPEG-DASH-видео в MP4 через FFmpeg;
- двусторонние ответы с таблицей соответствий MAX message ID ↔ Matrix event ID;
- Matrix → MAX реакции и экспериментальная обработка MAX → Matrix;
- телефон контакта в теме личной комнаты и команда `contact`;
- локальный инструмент аудита неиспользуемых Synapse ghost-аккаунтов.

### Известные ограничения

- MAX → Matrix реакции могут не приходить из-за отсутствия push-события;
- не поддерживаются редактирование, удаление и backfill истории;
- нет E2EE и double puppeting;
- inline keyboard и часть служебных вложений пропускаются.
