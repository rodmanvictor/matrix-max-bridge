# matrix-max-bridge

Мост Matrix ↔ MAX на `mautrix-python` и PyMax. Продолжает `pymatrix-max` от NijazKa (MIT), происхождение описано в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Локальный API и утилиты — в [API.md](API.md), изменения — в [CHANGELOG.md](CHANGELOG.md).

## Проверка

Тесты работают без сети, на подставных объектах:

```bash
docker build -t matrix-max-bridge:dev .
docker run --rm --network none -v "$PWD:/work:ro" -w /work \
  -e PYTHONPATH=/work:/work/vendor/pymax/src --entrypoint python \
  matrix-max-bridge:dev -m unittest discover -s tests -p 'test_*.py'
python tools/check_release.py
```

Тесты не доказывают, что MAX примет запрос. Новое поведение проверяй на «Избранном» своего аккаунта MAX: это чат с номером `0`.

## Правила

- Сессия MAX даёт полный доступ к аккаунту. Не запускай вторую копию клиента с той же сессией, не копируй и не коммить файлы сессии.
- Не выводи в чат, логи и коммиты тексты личных сообщений, коды входа, QR, токены и номера телефонов. При проверках печатай время, номер и длину сообщения, а не текст.
- Отправляй сообщения в чужие чаты только по прямому указанию владельца аккаунта. Для проверок есть «Избранное».
- MAX отправляет отложенные сообщения с точностью до минуты. Сообщения подряд ставь на разные минуты.
- PyMax — неофициальный клиент, протокол MAX может измениться. Если что-то перестало работать, сначала проверь на «Избранном».
- Библиотека PyMax лежит в `vendor/pymax` целиком. Правки в ней описывай в `THIRD_PARTY_NOTICES.md`.
- Документация и сообщения пользователю — на русском.
